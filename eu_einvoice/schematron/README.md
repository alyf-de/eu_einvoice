`XRechnung-CII-validation.xsl` can be downloaded from https://github.com/itplr-kosit/xrechnung-schematron/releases. It is in `schematron/cii/` of the release ZIP.

`EN16931-CII-validation-preprocessed.xsl`, `FACTUR-X_BASIC.xsl` and `FACTUR-X_EXTENDED.xsl` can be generated by following these steps:

- Download `en16931-cii-<version>.zip` from https://github.com/ConnectingEurope/eInvoicing-EN16931/releases. Copy `schematron/preprocessed/EN16931-CII-validation-preprocessed.sch` into a folder.
- Download the ZUGFeRD spec from https://www.ferd-net.de/publikationen-produkte/publikationen/detailseite/zugferd-252-english. Copy the following files from the `Schema/` folder into the same folder:
  - `2_Factur-X_<version>_BASIC/FACTUR-X_BASIC.sch`
  - `2_Factur-X_<version>_BASIC/FACTUR-X_BASIC_codedb.xml`
  - `4_Factur-X_<version>_EXTENDED/FACTUR-X_EXTENDED.sch`
  - `4_Factur-X_<version>_EXTENDED/FACTUR-X_EXTENDED_codedb.xml`
- Download `schxslt-1.10.1-xslt-only.zip` from https://codeberg.org/SchXslt/schxslt/releases/tag/v1.10.1, unzip and copy into the same folder.
- Run the following Python code in the same folder.
- Copy the generated `.xsl` files and the `_codedb.xml` files into this folder. The Factur-X `.xsl` files load the `_codedb.xml` files by name, so keep the file names.

```python
from saxonche import PySaxonProcessor

SCHEMATRON_FILES = [
	"EN16931-CII-validation-preprocessed.sch",
	"FACTUR-X_BASIC.sch",
	"FACTUR-X_EXTENDED.sch",
]
SCHEMATRON_PIPELINE = "schxslt-1.10.1/2.0/pipeline-for-svrl.xsl"


with PySaxonProcessor(license=False) as proc:
	xslt30_processor = proc.new_xslt30_processor()
	xslt30_processor.set_cwd(".")

	for sch_file in SCHEMATRON_FILES:
		xslt30_processor.transform_to_file(
			source_file=sch_file, stylesheet_file=SCHEMATRON_PIPELINE, output_file=sch_file[:-4] + ".xsl"
		)
```
